# 技术架构文档
## Grepu (歸朴) - 开发框架与实现方式

---

## 1. 技术选型

### 1.1 开发平台
- **平台**：iOS（MVP版本）
- **开发语言**：Swift 5.7+
- **UI框架**：SwiftUI
- **最低系统版本**：iOS 15.0+
- **开发工具**：Xcode 14.0+

### 1.2 架构模式
- **架构模式**：MVVM（Model-View-ViewModel）
- **数据流**：Combine框架（响应式编程）
- **依赖注入**：使用协议和依赖注入容器

### 1.3 核心技术栈

#### 前端技术
- **UI框架**：SwiftUI
- **动画**：SwiftUI Animation + Core Animation
- **图表**：Swift Charts（iOS 16+）或 Charts第三方库
- **3D渲染**：SceneKit（心灵世界3D效果）

#### 数据存储
- **本地数据库**：CoreData
- **云同步**：CloudKit
- **轻量数据**：UserDefaults
- **Keychain**：敏感信息存储（订阅凭证等）

#### 网络与API
- **网络请求**：URLSession + Combine
- **JSON解析**：Codable协议
- **API设计**：RESTful API（如需要后端）

#### 第三方SDK
- **健康数据**：HealthKit
- **订阅管理**：StoreKit 2
- **广告**：Google AdMob 或 Facebook Audience Network
- **分析**：Firebase Analytics（可选）
- **多语言管理**：内部自建导入工具或后端接口（Excel → JSON/Strings）

### 4.6 多语言系统

#### 4.6.1 架构组件
- **LocalizationService**：负责多语言资源的加载、缓存与热更新
- **LocalizationRepository**：维护本地JSON/Strings文件，支持增量更新
- **LocalizationImporter**（工具链）：将Excel或后端提供的Key-Value数据转换为应用内JSON/Strings

#### 4.6.2 数据流程
```
Excel多语言文档/后台接口 → LocalizationImporter → 输出多语言JSON/Strings → 
打包至Resources/Localization/ → 应用启动时加载 → LocalizationService注入
```

#### 4.6.3 Excel导入规范
- **字段要求**：首列为`key`，后续列对应语言（如`zh-Hans`、`en`、`ja`）
- **数据校验**：导入时检查Key唯一性、占位符一致性（如`%@`、`%d`）
- **版本管理**：生成`metadata.json`记录语言版本号、生成时间、制表人
- **增量策略**：支持仅导入发生变动的Key，应用端通过版本号判断是否刷新

#### 4.6.4 运行时策略
- **启动加载**：优先读取本地默认语言包
- **语言切换**：LocalizationService更新当前语言，发布`Combine`通知驱动UI刷新
- **后台更新**：可选对接后端接口，定期轮询最新语言包并持久化到本地
- **降级方案**：缺失Key时回退到默认语言，避免展示占位符

### 4.7 主题与暗黑模式

#### 4.7.1 主题管理架构
- **ThemeService**：负责主题资源加载、当前主题状态管理
- **ThemeRepository**：存储主题配置（JSON/Plist），包含颜色、字体、插画、图标集合
- **ThemeModel**：
  ```swift
  struct Theme {
      let id: String
      let name: [String: String]       // 多语言名称
      let palette: ColorPalette        // 颜色配置（浅色/深色）
      let typography: TypographyConfig // 字体与字号
      let assets: ThemeAssets          // 插画、图标资源引用
      let isPremium: Bool              // 是否订阅专属
  }
  ```

#### 4.7.2 主题类型与权限
- **系统主题**：浅色/暗黑模式支持，跟随系统`ColorScheme`
- **自定义主题**：共3套——1套默认主题（免费）、2套订阅专属主题
- **权限控制**：
  - ThemeService与SubscriptionService联动校验`isPremium`
  - 非订阅用户选取付费主题时弹出升级提示
  - 订阅用户可即时切换任意主题

#### 4.7.3 主题配置格式
```json
{
  "id": "serenity",
  "name": {
    "zh-Hans": "澄澈之境",
    "en": "Serenity"
  },
  "palette": {
    "light": {
      "primary": "#6B9BD2",
      "background": "#FFFFFF"
    },
    "dark": {
      "primary": "#8BC34A",
      "background": "#0F172A"
    }
  },
  "assets": {
    "illustration": "Themes/Serenity/main",
    "iconSet": "Themes/Serenity/icons"
  },
  "isPremium": true
}
```

#### 4.7.4 UI层实现
- **环境注入**：通过SwiftUI `EnvironmentKey`或`@EnvironmentObject`提供当前主题
- **动态刷新**：ThemeService发布主题变更事件，界面组件监听并响应
- **暗黑适配**：主题配置明确提供`light/dark`两套配色，确保可读性
- **状态持久化**：用户选择写入`UserDefaults`/`@AppStorage`，支持多设备同步

#### 4.7.5 设计资源管理
- 主题插画、图标存放在`Resources/Themes/主题ID/`
- 通过命名约定（如`themeID_iconName`）避免资源冲突
- 支持通过远程配置下发新主题，下载后写入本地缓存

## 5. 性能优化

### 5.1 启动优化
- 延迟加载非关键资源
- 使用异步加载数据
- 优化首屏渲染时间

### 5.2 内存优化
- 及时释放不需要的资源
- 使用弱引用避免循环引用
- 图片资源使用适当尺寸

### 5.3 动画优化
- 使用GPU加速的动画属性
- 避免在主线程进行复杂计算
- 使用`@State`和`@Binding`优化状态更新
- 主题切换、语言切换时使用局部过渡，避免整页闪烁

### 5.4 数据优化
- 分页加载大量数据
- 使用索引优化数据库查询
- 缓存常用数据
- 多语言包与主题配置启用版本化缓存，按需刷新
