# Grepu (歸朴) 项目总览

---

## 项目信息

**项目名称**：Grepu (歸朴)  
**中文名**：歸朴 (Guī Pǔ)  
**副标题**：构建全新的内心世界  
**项目类型**：冥想与放松类移动应用（iOS优先）  
**MVP版本**：v1.0

---

## 项目背景

当前职场焦虑和失眠人群越来越多，希望可以有一款可以让用户通过"呼吸"的调整，来实现冥想和放松。每天只需要3-5mins的时间，就可以极大限度的恢复精神力。因此，希望可以通过类似于forest这样游戏化的养成方案，实现用户在放松心情减少焦虑的同时，通过建立属于自己的心灵世界。

---

## 核心功能

### MVP版本功能清单

1. ✅ **整体APP框架构建**
   - 底部Tab导航（首页、心灵世界、报告、我的）
   - 设计规范系统
   - 基础组件库
   - 通用功能（新手引导、权限管理、错误处理）

2. ✅ **付费订阅功能**
   - 月度/年度订阅方案
   - StoreKit 2集成
   - 权限控制
   - 订阅管理

3. ✅ **呼吸引导功能**
   - 多种呼吸引导类型（免费/订阅）
   - 呼吸动画和节奏控制
   - 背景音乐和震动反馈
   - 练习数据记录

4. ✅ **心灵世界功能**
   - 游戏化养成系统
   - 能量值系统
   - 元素解锁和放置
   - 成就系统
   - 3D/2D世界场景

5. ✅ **个人中心**
   - 用户信息管理
   - 数据统计展示
   - 设置功能（语言、主题、通知、隐私）
   - 帮助和反馈

6. ✅ **弹窗广告功能**
   - 激励视频广告
   - 插屏广告
   - 广告展示规则
   - 用户体验优化

7. ✅ **Apple Health数据整合**
   - 睡眠数据读取和分析
   - 心率数据读取和分析
   - 健康报告生成
   - 数据可视化

8. ✅ **多语言与主题系统**
   - Excel/后台接口导入Key-Value文案
   - 设置中一键切换语言（即时生效）
   - 三套主题（1套免费 + 2套订阅专属），支持浅色/暗黑模式联动

## 开发计划

### 开发阶段

1. **需求分析**：1周
   - 需求确认
   - 技术调研
   - 原型设计

2. **UI/UX设计**：2周
   - 视觉设计
   - 交互设计
   - 设计规范

3. **架构搭建**：1周
   - 项目结构
   - 基础框架
   - 数据模型

4. **核心功能开发**：6-8周
   - 整体框架（1周）
   - 呼吸引导功能（2周）
   - 心灵世界功能（2周）
   - 订阅功能（1周）
   - 个人中心（1周）
   - 广告功能（1周）
   - Health数据整合（1周）

5. **测试与优化**：2周
   - 功能测试
   - 性能优化
   - Bug修复

6. **审核与发布**：1-2周
   - App Store审核
   - 发布准备

### 总计
- **预计总时长**：12-15周（3-4个月）
- **团队规模**：2-3人（iOS开发、UI设计、产品）

## 技术栈

### 开发平台
- **平台**：iOS
- **开发语言**：Swift 5.7+
- **UI框架**：SwiftUI
- **最低系统版本**：iOS 15.0+
- **开发工具**：Xcode 14.0+

### 核心技术
- **架构模式**：MVVM
- **数据流**：Combine
- **数据存储**：CoreData + CloudKit
- **健康数据**：HealthKit
- **订阅管理**：StoreKit 2
- **广告SDK**：Google AdMob
- **3D渲染**：SceneKit

## 商业模式

### 收入模式
- **订阅制（主要）**：月度¥28/月，年度¥268/年
- **广告收入（免费版）**：激励视频和插屏广告

### 功能对比
| 功能 | 免费版 | 订阅版 |
|------|--------|--------|
| 基础呼吸引导 | ✓ (3种) | ✓ (全部) |
| 每日练习次数 | 3次 | 无限 |
| 基础元素 | ✓ (5种) | ✓ (全部) |
| 健康报告 | ✓ (7天) | ✓ (全部历史) |
| 广告 | ✗ | ✓ (无广告) |

## 成功指标（KPI）

### 用户指标
- **DAU/MAU**：日活跃用户数/月活跃用户数
- **留存率**：次日留存、7日留存、30日留存
- **使用时长**：平均单次使用时长、日均使用时长

### 业务指标
- **付费转化率**：免费用户转订阅用户比例
- **ARPU**：每用户平均收入
- **LTV**：用户生命周期价值
- **CAC**：用户获取成本

### 产品指标
- **完成率**：呼吸引导完成率
- **解锁率**：心灵世界元素解锁率
- **报告查看率**：健康报告查看率

## 风险与挑战

### 市场风险
- 竞争激烈：冥想应用市场已有成熟产品
- 用户教育：需要教育用户呼吸引导的价值
- 付费意愿：需要验证用户付费意愿

### 产品风险
- 技术实现：Apple Health数据获取和展示的复杂性
- 内容质量：呼吸引导音频/视频的质量要求高
- 游戏化平衡：游戏化程度需要平衡，避免过度娱乐化

### 运营风险
- 用户流失：需要持续的内容更新和功能迭代
- 数据隐私：健康数据隐私保护要求高
- 平台政策：需要遵守Apple的订阅和广告政策
