# 功能需求文档 - 呼吸引导功能

---

## 1. 功能概述

呼吸引导功能是Grepu的核心功能，通过视觉和听觉引导用户进行呼吸练习，帮助用户在3-5分钟内实现放松和恢复精神力。

---

## 2. 功能流程

### 2.1 整体流程
```
选择引导 → 准备界面 → 引导界面 → 完成界面 → 返回/分享
```

### 2.2 详细流程

#### 步骤1：选择引导
- **入口**：首页"快速开始"按钮或引导列表
- **展示内容**：
  - 引导类型列表
  - 每个引导显示：名称、时长、难度、是否免费
- **用户操作**：点击选择引导

#### 步骤2：准备界面
- **展示内容**：
  - 引导名称和简介
  - 预计时长
  - 背景音乐选择（可选）
  - 提示信息（如：找一个安静的地方）
- **用户操作**：
  - 选择背景音乐（可选）
  - 点击"开始"按钮
  - 点击"返回"按钮

#### 步骤3：引导界面
- **展示内容**：
  - 呼吸动画（中心）
  - 当前阶段提示（顶部）
  - 进度条和剩余时间（底部）
  - 暂停/继续按钮
- **用户操作**：
  - 跟随动画进行呼吸
  - 点击暂停/继续
  - 点击退出（需确认）

#### 步骤4：完成界面
- **展示内容**：
  - 完成动画
  - 本次练习信息
  - 获得的能量值
  - 解锁的元素（如有）
  - 连续天数提示
- **用户操作**：
  - 点击"返回"按钮
  - 点击"分享"按钮
  - 点击"再来一次"按钮

## 3. 引导类型

### 3.1 基础呼吸（免费）

#### 3.1.1 4-7-8呼吸法
- **节奏**：4秒吸气 → 7秒屏息 → 8秒呼气
- **时长**：5分钟（约8个循环）
- **适用场景**：睡前放松、焦虑缓解
- **难度**：初级

#### 3.1.2 等长呼吸
- **节奏**：4秒吸气 → 4秒屏息 → 4秒呼气 → 4秒停顿
- **时长**：3分钟（约10个循环）
- **适用场景**：日常放松、专注提升
- **难度**：初级

#### 3.1.3 深度呼吸
- **节奏**：5秒吸气 → 5秒屏息 → 5秒呼气
- **时长**：4分钟（约8个循环）
- **适用场景**：压力释放、情绪调节
- **难度**：初级

### 3.2 场景化呼吸（订阅）

#### 3.2.1 睡前放松
- **节奏**：6秒吸气 → 4秒屏息 → 8秒呼气 → 4秒停顿
- **时长**：5分钟
- **适用场景**：睡前准备
- **难度**：中级

#### 3.2.2 工作间隙
- **节奏**：3秒吸气 → 3秒屏息 → 3秒呼气
- **时长**：3分钟
- **适用场景**：工作休息
- **难度**：初级

#### 3.2.3 焦虑缓解
- **节奏**：4秒吸气 → 4秒屏息 → 6秒呼气
- **时长**：4分钟
- **适用场景**：焦虑时使用
- **难度**：中级

#### 3.2.4 专注提升
- **节奏**：5秒吸气 → 2秒屏息 → 5秒呼气 → 2秒停顿
- **时长**：5分钟
- **适用场景**：需要专注时
- **难度**：中级

#### 4.2.2 呼吸动画设计

##### 动画效果
- **吸气阶段**：
  - 圆圈从小到大（scale: 1.0 → 1.3）
  - 颜色从浅到深（opacity: 0.6 → 1.0）
  - 持续时间：根据节奏（如4秒）
  
- **屏息阶段**：
  - 圆圈保持最大状态
  - 轻微脉冲效果（scale: 1.3 → 1.32 → 1.3）
  - 持续时间：根据节奏（如7秒）
  
- **呼气阶段**：
  - 圆圈从大到小（scale: 1.3 → 1.0）
  - 颜色从深到浅（opacity: 1.0 → 0.6）
  - 持续时间：根据节奏（如8秒）

##### 动画实现
- 使用SwiftUI的`scaleEffect`和`opacity`动画
- 使用`withAnimation`控制动画时长
- 动画时长与呼吸节奏同步

#### 4.2.3 阶段提示
- **位置**：顶部居中
- **内容**：当前阶段文字（吸气/屏息/呼气）
- **样式**：大字号、主色调
- **动画**：阶段切换时淡入淡出

#### 4.2.4 进度显示
- **进度条**：
  - 位置：底部
  - 样式：圆角进度条
  - 颜色：主色调渐变
  - 更新：实时更新
  
- **剩余时间**：
  - 位置：进度条下方
  - 格式：MM:SS
  - 更新：每秒更新

#### 4.2.5 控制按钮
- **暂停/继续按钮**：
  - 位置：左下角
  - 功能：暂停/继续引导
  - 状态切换：暂停时显示"继续"
  
- **退出按钮**：
  - 位置：右下角
  - 功能：退出引导
  - 确认：点击后弹出确认弹窗

## 5. 交互逻辑

### 5.1 呼吸节奏控制

#### 5.1.1 节奏计算
```swift
struct BreathingRhythm {
    let inhaleDuration: TimeInterval  // 吸气时长
    let holdDuration: TimeInterval     // 屏息时长
    let exhaleDuration: TimeInterval   // 呼气时长
    let pauseDuration: TimeInterval?   // 停顿时长（可选）
    
    var totalCycleDuration: TimeInterval {
        return inhaleDuration + holdDuration + exhaleDuration + (pauseDuration ?? 0)
    }
}
```

#### 5.1.2 状态机
```swift
enum BreathingPhase {
    case idle
    case inhaling(remaining: TimeInterval)
    case holding(remaining: TimeInterval)
    case exhaling(remaining: TimeInterval)
    case pausing(remaining: TimeInterval)
}
```

#### 5.1.3 计时器实现
- 使用`Timer`或`DispatchSourceTimer`
- 每秒更新一次状态
- 状态切换时触发动画

### 5.2 暂停/继续逻辑

#### 5.2.1 暂停
- 停止计时器
- 暂停动画（保持当前状态）
- 暂停背景音乐
- 更新按钮文字为"继续"

#### 5.2.2 继续
- 恢复计时器
- 恢复动画
- 恢复背景音乐
- 更新按钮文字为"暂停"

#### 5.2.3 数据记录
- 记录暂停次数
- 记录总暂停时长
- 暂停时间不计入练习时长

### 5.3 退出逻辑

#### 5.3.1 退出确认
- 点击退出按钮
- 弹出确认弹窗：
  - 标题："确定要退出吗？"
  - 内容："您的进度将不会保存"
  - 按钮："取消"、"确定退出"

#### 5.3.2 退出处理
- 停止计时器
- 停止动画
- 停止背景音乐
- 记录为"未完成"状态
- 返回上一页

### 5.4 完成逻辑

#### 5.4.1 完成判断
- 所有循环完成
- 或用户主动点击"完成"（可选）

#### 5.4.2 数据记录
- 记录练习数据：
  - 开始时间
  - 结束时间
  - 实际时长
  - 完成状态
  - 暂停次数
  - 引导类型
  
- 计算能量值：
  - 基础能量：10
  - 连续天数奖励（如有）
  - 总能量值

#### 5.4.3 成就检查
- 检查是否解锁新成就
- 检查是否解锁新元素
- 更新连续天数

## 6. 背景音乐

### 6.1 音乐选项
- **无**：不播放音乐
- **自然音**：鸟鸣、流水等自然声音
- **轻音乐**：舒缓的纯音乐

### 6.2 音乐控制
- **音量**：可调节（0-100%）
- **淡入淡出**：开始和结束时淡入淡出
- **循环播放**：音乐循环播放
- **后台播放**：支持后台播放（可选）

### 6.3 音乐文件
- **格式**：MP3或AAC
- **时长**：5-10分钟（循环播放）
- **大小**：< 5MB/首
- **存储**：本地存储

## 7. 震动反馈（可选）

### 7.1 震动时机
- **阶段切换**：吸气→屏息、屏息→呼气时轻微震动
- **完成**：完成所有循环时成功震动

### 7.2 震动强度
- **阶段切换**：轻微震动（UIImpactFeedbackGenerator.medium）
- **完成**：成功震动（UINotificationFeedbackGenerator.success）

### 7.3 设置控制
- 用户可在设置中开启/关闭震动
- 默认开启
