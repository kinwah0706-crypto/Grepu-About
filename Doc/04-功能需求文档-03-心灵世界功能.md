# 功能需求文档 - 心灵世界功能

---

## 1. 功能概述

心灵世界是Grepu的游戏化核心功能，用户通过完成呼吸引导获得能量值，使用能量值解锁和放置元素，逐步构建属于自己的3D/2D心灵世界。

---

## 2. 功能流程

### 2.1 整体流程
```
查看世界 → 选择元素 → 放置元素 → 查看成就 → 分享世界
```

### 2.2 详细流程

#### 步骤1：查看世界
- **入口**：底部Tab"心灵世界"
- **展示内容**：
  - 3D/2D心灵世界场景
  - 已放置的元素
  - 能量值显示
  - 成就展示
- **用户操作**：
  - 旋转/缩放视角（3D）
  - 点击元素查看详情
  - 点击"+"添加元素

#### 步骤2：选择元素
- **触发**：点击"+"按钮
- **展示内容**：
  - 元素商店
  - 可解锁元素列表
  - 每个元素显示：名称、图标、解锁条件、能量值消耗
- **用户操作**：
  - 浏览元素
  - 点击未解锁元素查看解锁条件
  - 点击已解锁元素进行放置

#### 步骤3：放置元素
- **触发**：选择已解锁元素
- **展示内容**：
  - 世界场景（半透明元素预览）
  - 放置提示
- **用户操作**：
  - 在世界中点击位置
  - 确认放置
  - 取消放置

#### 步骤4：查看成就
- **触发**：点击成就入口
- **展示内容**：
  - 成就列表
  - 已解锁/未解锁成就
  - 成就进度
- **用户操作**：
  - 查看成就详情
  - 查看解锁奖励

#### 步骤5：分享世界
- **触发**：点击分享按钮
- **展示内容**：
  - 分享选项（截图、卡片）
  - 社交平台选择
- **用户操作**：
  - 选择分享方式
  - 选择分享平台

## 3. 能量值系统

### 3.1 能量值获取

#### 3.1.1 基础获取
- **完成一次呼吸引导**：+10能量值
- **完成状态要求**：必须完成（中途退出不获得）

#### 3.1.2 连续奖励
- **连续7天完成**：+50能量值（额外奖励）
- **连续30天完成**：+200能量值（额外奖励）
- **连续奖励规则**：
  - 每天只计算一次
  - 中断后重新计算
  - 奖励在完成第7天/第30天时发放

#### 3.1.3 成就奖励
- **首次完成**：+20能量值
- **坚持者（连续7天）**：+50能量值（与连续奖励叠加）
- **习惯养成（连续30天）**：+200能量值（与连续奖励叠加）
- **深度放松（累计100次）**：+100能量值
- **心灵大师（累计1000次）**：+500能量值

### 3.2 能量值消耗

#### 3.2.1 元素解锁消耗
| 元素类型 | 能量值消耗 |
|---------|-----------|
| 小树苗 | 10 |
| 花朵 | 30 |
| 小房子 | 100 |
| 大树 | 150 |
| 湖泊 | 300 |
| 特殊元素 | 200-500 |

#### 3.2.2 消耗规则
- 解锁元素时立即扣除能量值
- 能量值不足时无法解锁
- 解锁后元素永久拥有

### 3.3 能量值显示

#### 3.3.1 显示位置
- **心灵世界页面顶部**：当前能量值（大号显示）
- **元素商店**：当前能量值（小号显示）
- **个人中心**：总获得能量值、总消耗能量值

#### 3.3.2 显示格式
- **当前能量值**：`⚡ 150`（图标 + 数字）
- **能量值变化**：获得时显示`+10`动画，消耗时显示`-30`动画

## 4. 元素系统

### 4.1 元素分类

#### 4.1.1 地形元素
- **基础草地**：初始解锁，0能量值
- **湖泊**：连续30天，300能量值
- **小山**：累计100次，250能量值
- **路径**：累计50次，50能量值

#### 4.1.2 植物元素
- **小树苗**：完成1次，10能量值
- **花朵**：完成3次，30能量值
- **大树**：连续7天，150能量值
- **花丛**：累计20次，80能量值
- **竹林**：累计200次，400能量值

#### 4.1.3 建筑元素
- **小房子**：完成10次，100能量值
- **凉亭**：连续14天，200能量值
- **桥梁**：累计50次，150能量值
- **灯塔**：累计500次，600能量值

#### 4.1.4 装饰元素
- **石头**：完成5次，20能量值
- **小动物**：连续3天，40能量值
- **云朵**：累计30次，60能量值
- **彩虹**：连续30天，500能量值（特殊）

#### 4.1.5 特殊元素（订阅专属）
- **水晶**：订阅用户专属，200能量值
- **魔法树**：订阅用户专属，300能量值
- **星空**：订阅用户专属，400能量值

### 4.2 元素属性

#### 4.2.1 基础属性
```swift
struct GardenElement {
    let id: UUID
    let type: ElementType
    let name: String
    let icon: String
    let model: String  // 3D模型文件路径
    let unlockCondition: UnlockCondition
    let energyCost: Int
    let size: CGSize  // 占用大小
    let category: ElementCategory
}
```

#### 4.2.2 解锁条件
```swift
enum UnlockCondition {
    case initial  // 初始解锁
    case completeCount(Int)  // 完成次数
    case consecutiveDays(Int)  // 连续天数
    case achievement(String)  // 成就解锁
    case subscription  // 订阅专属
}
```

## 5. 世界场景

### 5.1 场景设计

#### 5.1.1 基础场景
- **地形**：基础草地（初始）
- **大小**：10x10单位（可扩展）
- **背景**：天空渐变（蓝色到白色）
- **光照**：柔和的环境光

#### 5.1.2 3D场景（推荐）
- **视角**：等距视角或自由视角
- **相机控制**：
  - 双指缩放
  - 单指拖拽旋转
  - 双击重置视角
  
- **渲染**：使用SceneKit
- **性能**：支持最多100个元素流畅运行

#### 5.1.3 2D场景（备选）
- **视角**：俯视图
- **相机控制**：
  - 双指缩放
  - 单指拖拽平移
  
- **渲染**：使用SpriteKit或SwiftUI
- **性能**：支持更多元素

### 5.2 元素放置

#### 5.2.1 放置模式
- **触发**：选择已解锁元素
- **进入放置模式**：
  - 世界场景显示半透明元素预览
  - 显示放置提示
  - 禁用其他操作

#### 5.2.2 放置规则
- **碰撞检测**：元素不能重叠
- **边界检测**：元素不能超出世界边界
- **地形限制**：某些元素只能放在特定地形上（如湖泊只能放在草地上）

#### 5.2.3 放置交互
- **点击放置**：在世界中点击位置放置
- **拖拽调整**：放置后可以拖拽调整位置
- **旋转调整**：长按元素可以旋转（可选）
- **确认放置**：点击确认按钮完成放置
- **取消放置**：点击取消按钮退出放置模式

#### 5.2.4 放置反馈
- **有效位置**：显示绿色高亮
- **无效位置**：显示红色高亮
- **放置成功**：播放放置动画
- **放置失败**：显示错误提示

### 5.3 元素管理

#### 5.3.1 查看元素
- **点击元素**：显示元素详情
  - 元素名称
  - 解锁时间
  - 放置时间
  - 操作选项（移动、删除）

#### 5.3.2 移动元素
- **触发**：长按元素或点击"移动"
- **操作**：拖拽到新位置
- **限制**：同样需要满足放置规则

#### 5.3.3 删除元素
- **触发**：点击"删除"
- **确认**：弹出确认弹窗
- **返还**：删除后返还50%能量值
- **限制**：基础地形不能删除

## 6. 成就系统

### 6.1 成就类型

#### 6.1.1 完成类成就
- **首次完成**：完成第一次呼吸引导
- **坚持者**：连续7天完成
- **习惯养成**：连续30天完成
- **深度放松**：累计完成100次
- **心灵大师**：累计完成1000次

#### 6.1.2 世界类成就
- **初建者**：放置第一个元素
- **园艺师**：放置10个元素
- **建筑师**：放置50个元素
- **世界创造者**：放置100个元素

#### 6.1.3 能量类成就
- **能量收集者**：累计获得100能量值
- **能量大师**：累计获得1000能量值
- **能量传奇**：累计获得10000能量值

### 6.2 成就奖励

#### 6.2.1 奖励类型
- **能量值奖励**：直接获得能量值
- **元素解锁**：解锁特殊元素
- **主题解锁**：解锁专属主题（可选）
- **徽章**：获得成就徽章

#### 6.2.2 奖励发放
- **自动发放**：达成条件时自动发放
- **通知提醒**：发放时显示通知
- **成就页面**：在成就页面查看

### 6.3 成就展示

#### 6.3.1 成就页面
- **布局**：网格布局，每个成就一个卡片
- **状态**：
  - 已解锁：彩色显示，显示解锁时间
  - 未解锁：灰色显示，显示进度
- **详情**：点击查看成就详情和奖励

#### 6.3.2 成就进度
- **进度条**：显示当前进度和目标
- **进度更新**：实时更新
- **进度提示**：接近完成时提示

## 7. 分享功能

### 7.1 分享内容

#### 7.1.1 世界截图
- **内容**：当前心灵世界的截图
- **格式**：PNG或JPG
- **质量**：高清（支持分享到社交平台）

#### 7.1.2 分享卡片
- **内容**：
  - 世界截图
  - 用户昵称
  - 成就信息（如：连续X天）

### 8.1 存储内容
- **用户世界数据**：
  - 世界ID
  - 已解锁元素列表
  - 已放置元素列表（位置、旋转等）

  - 当前能量值

  - 成就进度

### 8.2 数据同步

## 9. 性能优化

### 9.1 渲染优化
- **元素LOD**：远距离元素使用简化模型
- **遮挡剔除**：不渲染被遮挡的元素
- **批量渲染**：相同元素批量渲染

### 9.2 内存优化
- **模型加载**：按需加载元素模型
- **纹理压缩**：使用压缩纹理格式
- **资源释放**：及时释放不用的资源

### 9.3 交互优化
- **触摸响应**：优化触摸检测算法
- **动画流畅**：使用GPU加速动画
- **加载优化**：异步加载资源
