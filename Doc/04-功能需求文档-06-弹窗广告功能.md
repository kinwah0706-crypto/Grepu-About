# 功能需求文档 - 弹窗广告功能

---

## 1. 功能概述

弹窗广告功能是Grepu免费版的重要变现方式，通过展示激励视频广告和插屏广告，在提供免费服务的同时获得广告收入。订阅用户不显示广告。

---

## 2. 广告类型

### 2.1 激励视频广告（Rewarded Video Ad）

#### 2.1.1 功能说明
- **广告形式**：全屏视频广告
- **用户行为**：观看完整视频（通常15-30秒）
- **奖励机制**：观看完成后获得额外能量值
- **关闭方式**：观看完成后可关闭，或跳过（如允许）

#### 2.1.2 奖励内容
- **基础奖励**：+20能量值
- **每日限制**：每天最多观看3次
- **奖励提示**：观看前显示奖励内容

#### 2.1.3 展示场景
- **完成呼吸引导后**：可选择观看广告获得额外能量
- **能量值不足时**：提示观看广告获得能量
- **主动入口**：个人中心提供"观看广告"入口

### 2.2 插屏广告（Interstitial Ad）

#### 2.2.1 功能说明
- **广告形式**：全屏图片或视频广告
- **展示时机**：特定操作完成后
- **关闭方式**：5秒后显示关闭按钮
- **强制观看**：必须等待5秒才能关闭

#### 2.2.2 展示场景
- **完成呼吸引导后**（免费用户）
- **打开应用时**（每天首次，免费用户）
- **解锁元素时**（免费用户）

### 2.3 横幅广告（可选）

#### 2.3.1 功能说明
- **广告形式**：底部横幅广告
- **展示位置**：部分页面底部
- **关闭方式**：可关闭
- **优先级**：低（MVP版本可选）

## 3. 广告展示规则

### 3.1 展示条件

#### 3.1.1 用户条件
- **订阅状态**：仅免费用户显示
- **订阅用户**：完全不显示任何广告

#### 3.1.2 展示频率限制
- **插屏广告**：
  - 同一用户每天最多展示3次
  - 每次展示间隔至少30分钟
  - 同一场景每天最多1次
  
- **激励视频广告**：
  - 每天最多观看3次
  - 无时间间隔限制（用户主动触发）

#### 3.1.3 展示时机控制
```swift
class AdManager {
    private var adShowCount: Int = 0
    private var lastAdShowTime: Date?
    private var todayAdShows: [Date] = []
    
    func shouldShowInterstitial() -> Bool {
        // 检查订阅状态
        guard subscriptionStatus == .free else { return false }
        
        // 检查今日展示次数
        guard todayAdShows.count < 3 else { return false }
        
        // 检查时间间隔
        if let lastTime = lastAdShowTime {
            guard Date().timeIntervalSince(lastTime) > 1800 else {
                return false
            }
        }
        
        return true
    }
}
```

### 3.2 展示场景详情

#### 3.2.1 完成呼吸引导后
- **触发条件**：完成一次呼吸引导（免费用户）
- **广告类型**：插屏广告
- **展示时机**：完成界面显示前
- **展示逻辑**：
  - 检查今日是否已在此场景展示
  - 检查展示频率限制
  - 满足条件则展示广告
  - 广告关闭后显示完成界面

#### 3.2.2 打开应用时
- **触发条件**：每天首次打开应用（免费用户）
- **广告类型**：插屏广告
- **展示时机**：应用启动后，首页显示前
- **展示逻辑**：
  - 检查是否为今天首次打开
  - 检查展示频率限制
  - 满足条件则展示广告
  - 广告关闭后进入首页

#### 3.2.3 解锁元素时
- **触发条件**：解锁新元素（免费用户）
- **广告类型**：插屏广告
- **展示时机**：解锁成功后
- **展示逻辑**：
  - 检查今日是否已在此场景展示
  - 检查展示频率限制
  - 满足条件则展示广告
  - 广告关闭后继续操作

#### 3.2.4 主动观看激励视频
- **触发条件**：用户主动点击"观看广告"按钮
- **广告类型**：激励视频广告
- **展示时机**：用户点击后立即展示
- **展示逻辑**：
  - 检查今日观看次数
  - 未达上限则展示广告
  - 观看完成后发放奖励

## 4. 广告SDK集成

### 4.1 SDK选择

#### 4.1.1 推荐方案：Google AdMob
- **优势**：
  - 广告填充率高
  - 收益稳定
  - 支持多种广告类型
  - iOS支持完善
  
- **集成要求**：
  - 最低iOS版本：iOS 12.0+
  - 需要Google账号
  - 需要配置App ID和广告单元ID

#### 4.1.2 备选方案：Facebook Audience Network
- **优势**：
  - 广告质量高
  - 用户定位精准
  
- **劣势**：
  - 填充率可能较低
  - 需要Facebook账号

### 4.2 AdMob集成步骤

#### 4.2.1 项目配置
1. **添加依赖**：
   - 使用CocoaPods或SPM添加Google-Mobile-Ads-SDK
   
2. **配置Info.plist**：
   ```xml
   <key>GADApplicationIdentifier</key>
   <string>ca-app-pub-xxxxxxxxxxxxxxxx~xxxxxxxxxx</string>
   ```

3. **初始化SDK**：
   ```swift
   import GoogleMobileAds
   
   GADMobileAds.sharedInstance().start(completionHandler: nil)
   ```

#### 4.2.2 广告单元ID配置
- **插屏广告**：`ca-app-pub-xxxxxxxxxxxxxxxx/xxxxxxxxxx`
- **激励视频广告**：`ca-app-pub-xxxxxxxxxxxxxxxx/xxxxxxxxxx`
- **测试广告ID**：用于开发测试

### 4.3 广告加载策略

#### 4.3.1 预加载机制
- **插屏广告**：
  - 应用启动时预加载
  - 展示后立即重新加载
  - 保持至少1个广告就绪
  
- **激励视频广告**：
  - 需要时加载
  - 加载完成后才能展示

#### 4.3.2 加载失败处理
- **重试机制**：失败后延迟重试（如30秒后）
- **降级处理**：加载失败不阻塞用户操作
- **错误记录**：记录加载失败原因（用于优化）

## 5. 用户体验优化

### 5.1 广告展示体验

#### 5.1.1 加载提示
- **加载中**：显示"加载广告中..."提示
- **加载失败**：静默失败，不显示错误（避免影响体验）
- **加载超时**：5秒超时，放弃展示

#### 5.1.2 关闭按钮
- **插屏广告**：5秒后显示关闭按钮
- **激励视频**：观看完成后显示关闭按钮
- **按钮样式**：清晰的"×"或"关闭"按钮

#### 5.1.3 过渡动画
- **展示动画**：平滑的淡入动画
- **关闭动画**：平滑的淡出动画
- **避免突兀**：避免突然弹出

### 5.2 奖励体验

#### 5.2.1 奖励提示
- **观看前**：显示"观看广告可获得+20能量值"
- **观看中**：显示进度（如支持）
- **观看后**：显示"恭喜获得+20能量值"动画

#### 5.2.2 奖励发放
- **即时发放**：观看完成后立即发放
- **动画反馈**：能量值增加动画
- **数据更新**：立即更新能量值显示

### 5.3 订阅引导

#### 5.3.1 引导时机
- **广告展示后**：显示"升级Premium，享受无广告体验"
- **能量值不足时**：提示"订阅用户无限能量值"
- **个人中心**：显示订阅优势

#### 5.3.2 引导方式
- **轻量引导**：不强制，不打断用户
- **价值强调**：强调订阅的价值
- **便捷入口**：提供快速升级入口

## 7. 异常处理

### 7.1 广告加载异常

#### 7.1.1 网络错误
- **处理方式**：静默失败，不阻塞用户
- **重试机制**：延迟后自动重试
- **用户提示**：不显示错误（避免影响体验）

#### 7.1.2 广告填充失败
- **处理方式**：跳过广告展示
- **记录日志**：记录失败原因
- **优化策略**：调整广告请求频率

### 7.2 广告展示异常

#### 7.2.1 展示失败
- **处理方式**：继续正常流程
- **不阻塞**：不阻塞用户操作
- **记录日志**：记录失败原因

#### 7.2.2 广告崩溃
- **处理方式**：捕获异常，恢复应用
- **降级处理**：禁用广告功能（如频繁崩溃）
- **上报问题**：上报给广告SDK提供商

### 7.3 奖励发放异常

#### 7.3.1 奖励未发放
- **检测机制**：验证奖励是否发放
- **补偿机制**：自动补偿未发放的奖励
- **用户反馈**：提供客服入口

#### 7.3.2 重复发放
- **防重复机制**：记录已发放的奖励
- **去重逻辑**：防止重复发放
- **数据校验**：定期校验数据一致性
