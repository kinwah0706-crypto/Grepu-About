# 功能需求文档 - Apple Health数据整合

---

## 1. 功能概述

Apple Health数据整合功能是Grepu的重要差异化功能，通过读取用户的睡眠数据、心率数据等健康信息，结合呼吸练习数据，生成个性化的健康报告，帮助用户了解呼吸练习对健康的影响。

---

## 2. 功能流程

### 2.1 整体流程
```
权限请求 → 数据读取 → 数据处理 → 报告生成 → 报告展示
```

### 2.2 详细流程

#### 步骤1：权限请求
- **触发时机**：首次使用报告功能时
- **请求内容**：读取睡眠数据、心率数据权限
- **用户操作**：同意/拒绝权限请求

#### 步骤2：数据读取
- **数据来源**：Apple Health应用
- **读取方式**：通过HealthKit框架读取
- **读取频率**：每次打开报告时读取，或定时更新

#### 步骤3：数据处理
- **数据清洗**：处理异常数据
- **数据计算**：计算平均值、趋势等
- **数据关联**：关联呼吸练习数据

#### 步骤4：报告生成
- **生成内容**：健康报告数据
- **生成时机**：数据读取后立即生成
- **缓存机制**：缓存报告数据，减少重复计算

#### 步骤5：报告展示
- **展示内容**：健康数据可视化
- **交互功能**：查看详情、切换时间范围等

## 3. 权限管理

### 3.1 权限类型

#### 3.1.1 读取权限
- **睡眠数据**：读取睡眠分析数据
- **心率数据**：读取心率数据
- **呼吸数据**：读取呼吸频率数据（可选）

#### 3.1.2 写入权限（可选）
- **呼吸练习数据**：写入呼吸练习记录到Health
- **冥想数据**：写入冥想时长数据

### 3.2 权限请求

#### 3.2.1 请求时机
- **首次使用报告功能**：用户首次打开报告页面
- **权限被拒绝后**：用户尝试使用功能时再次请求
- **权限说明**：显示权限用途说明

#### 3.2.2 请求流程
```
显示权限说明 → 用户同意 → 调用HealthKit API → 获取权限结果
```

### 3.3 权限状态管理

#### 3.3.1 状态类型
- **未请求**：尚未请求权限
- **已授权**：用户已授权
- **已拒绝**：用户已拒绝
- **受限**：权限受限（如家长控制）

#### 3.3.2 状态检查
- **应用启动时**：检查权限状态

#### 3.3.3 权限被拒绝处理
- **引导用户**：显示权限说明和设置入口
- **提供替代方案**：仅使用呼吸练习数据生成报告
- **不强制**：不强制用户授权

## 4. 数据获取

### 4.1 睡眠数据

#### 4.1.1 数据类型
- **睡眠时长**：总睡眠时长
- **睡眠质量**：
  - 深度睡眠时长
  - 浅度睡眠时长
  - REM睡眠时长
  - 清醒时长
- **睡眠时间**：
  - 入睡时间
  - 醒来时间
  - 睡眠时间段

#### 4.1.2 数据读取
```swift
import HealthKit

let sleepType = HKCategoryType.categoryType(forIdentifier: .sleepAnalysis)!
let predicate = HKQuery.predicateForSamples(
    withStart: startDate,
    end: endDate,
    options: .strictStartDate
)

let query = HKSampleQuery(
    sampleType: sleepType,
    predicate: predicate,
    limit: HKObjectQueryNoLimit,
    sortDescriptors: nil
) { query, results, error in
    // 处理睡眠数据
}
```

#### 4.1.3 数据处理
- **数据清洗**：过滤异常数据（如超过24小时的睡眠）
- **数据计算**：
  - 平均睡眠时长
  - 睡眠质量评分
  - 睡眠趋势分析
- **数据关联**：关联呼吸练习时间

### 4.2 心率数据

#### 4.2.1 数据类型
- **静息心率**：静息时的心率
- **心率变异性（HRV）**：心率变异性数据
- **心率趋势**：心率变化趋势
- **心率范围**：最高心率、最低心率

#### 4.2.2 数据读取
```swift
let heartRateType = HKQuantityType.quantityType(forIdentifier: .heartRate)!
let predicate = HKQuery.predicateForSamples(
    withStart: startDate,
    end: endDate,
    options: .strictStartDate
)

let query = HKStatisticsQuery(
    quantityType: heartRateType,
    quantitySamplePredicate: predicate,
    options: [.discreteAverage, .discreteMin, .discreteMax]
) { query, statistics, error in
    // 处理心率数据
}
```

#### 4.2.3 数据处理
- **数据清洗**：过滤异常心率值（如<30或>200）
- **数据计算**：
  - 平均静息心率
  - 心率变异性趋势
  - 心率改善情况
- **数据关联**：关联呼吸练习前后的心率变化

### 4.3 呼吸数据（可选）

#### 4.3.1 数据类型
- **呼吸频率**：每分钟呼吸次数
- **呼吸深度**：呼吸深度数据（如支持）

#### 4.3.2 数据读取
- 类似心率和睡眠数据的读取方式
- 可选功能，如设备不支持则不读取

### 4.4 数据缓存

#### 4.4.1 缓存策略
- **本地缓存**：使用CoreData缓存Health数据
- **缓存时间**：缓存最近30天数据
- **更新频率**：每天更新一次，或用户手动刷新

#### 4.4.2 缓存更新
- **自动更新**：应用启动时检查并更新
- **手动更新**：用户下拉刷新
- **增量更新**：只更新新增数据

## 5. 健康报告

### 5.1 报告概览

#### 5.1.1 概览页面布局
```
┌─────────────────────────┐
│  健康报告               │
│                         │
│  [最近7天] [最近30天]   │
│                         │
│  ┌─────────────────┐   │
│  │ 平均睡眠时长    │   │
│  │ 7.5小时        │   │
│  │ ↑ 较上周+0.3h  │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │ 平均静息心率    │   │
│  │ 68 bpm         │   │
│  │ ↓ 较上周-2 bpm │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │ 呼吸练习完成率  │   │
│  │ 85%            │   │
│  │ ↑ 较上周+5%    │   │
│  └─────────────────┘   │
│                         │
│  健康趋势：             │
│  [查看详情]             │
└─────────────────────────┘
```

#### 5.1.2 关键指标
- **平均睡眠时长**：最近7天/30天的平均睡眠时长
- **平均静息心率**：最近7天/30天的平均静息心率
- **呼吸练习完成率**：完成练习的天数/总天数
- **健康趋势**：整体健康趋势（上升/下降/稳定）

#### 5.1.3 时间范围选择
- **最近7天**：显示最近7天数据（免费用户）
- **最近30天**：显示最近30天数据
- **全部历史**：显示全部历史数据（订阅用户）

### 5.2 睡眠分析

#### 5.2.1 睡眠趋势图
- **图表类型**：折线图
- **X轴**：日期
- **Y轴**：睡眠时长（小时）
- **数据点**：每日睡眠时长
- **趋势线**：显示整体趋势

#### 5.2.2 睡眠质量分布
- **图表类型**：堆叠柱状图
- **数据内容**：
  - 深度睡眠时长
  - 浅度睡眠时长
  - REM睡眠时长
  - 清醒时长
- **时间范围**：最近7天/30天

#### 5.2.3 睡眠洞察
- **自动生成**：基于数据分析生成洞察
- **洞察内容**：
  - "您的平均睡眠时长为7.5小时，建议保持8小时"
  - "本周睡眠质量较上周提升15%"
  - "建议在22:00前完成呼吸练习，有助于改善睡眠"
- **个性化**：根据用户数据个性化建议

#### 5.2.4 睡眠与呼吸练习关联
- **关联分析**：分析呼吸练习对睡眠的影响
- **展示内容**：
  - 完成呼吸练习后的睡眠质量变化
  - 最佳练习时间（对睡眠改善最有效的时间）
  - 练习频率与睡眠质量的关系

### 5.3 心率分析

#### 5.3.1 心率趋势图
- **图表类型**：折线图
- **X轴**：日期
- **Y轴**：心率（bpm）
- **数据点**：每日平均静息心率
- **参考线**：正常心率范围（60-100 bpm）

#### 5.3.2 心率变异性趋势
- **图表类型**：折线图
- **数据内容**：心率变异性（HRV）趋势
- **意义说明**：HRV越高，压力水平越低

#### 5.3.3 心率洞察
- **自动生成**：基于数据分析生成洞察
- **洞察内容**：
  - "您的静息心率为68 bpm，处于正常范围"
  - "心率变异性显示您的压力水平有所下降"
  - "建议增加呼吸练习频率，有助于降低心率"
- **个性化**：根据用户数据个性化建议

#### 5.3.4 心率与呼吸练习关联
- **关联分析**：分析呼吸练习对心率的影响
- **展示内容**：
  - 练习前后的心率变化
  - 长期练习对心率的影响趋势
  - 不同引导类型对心率的影响

### 5.4 综合报告

#### 5.4.1 健康评分
- **评分算法**：综合睡眠、心率、练习完成率计算
- **评分范围**：0-100分
- **评分说明**：
  - 90-100：优秀
  - 80-89：良好
  - 70-79：一般
  - <70：需要改善

#### 5.4.2 改善建议
- **自动生成**：基于数据分析生成建议
- **建议类型**：
  - 睡眠改善建议
  - 心率改善建议
  - 练习频率建议
  - 练习时间建议

#### 5.4.3 成就展示
- **健康成就**：基于健康数据解锁的成就
  - "优质睡眠"：连续7天睡眠质量>80%
  - "心率稳定"：连续30天心率在正常范围
  - "健康达人"：健康评分连续30天>85

## 6. 数据可视化

#### 6.1.1 折线图

- **特性**：
  - 支持缩放
  - 支持点击查看详情
  - 支持切换时间范围
  - 支持显示参考线

#### 6.1.2 柱状图
- **用途**：显示分类数据（睡眠质量分布）

  - 支持堆叠
  - 支持分组
  - 支持点击查看详情

#### 6.1.3 饼图（可选）
- **用途**：显示比例数据（睡眠质量占比）
- **特性**：
  - 支持点击查看详情
  - 支持动画效果

### 6.2 图表实现

#### 6.2.1 技术方案
- **iOS 16+**：使用Swift Charts（原生）

- **数据采样**：大量数据时进行采样

## 7. 数据隐私

### 7.1 隐私保护

#### 7.1.1 数据存储
- **本地存储**：所有健康数据仅存储在本地
- **不上传**：不上传到服务器
- **加密存储**：敏感数据加密存储

#### 7.1.2 数据使用
- **仅用于报告**：数据仅用于生成健康报告
- **不分享**：不向第三方分享数据
- **用户控制**：用户可随时撤销权限

### 7.2 隐私政策

#### 7.2.1 政策内容
- **数据收集**：说明收集的数据类型
- **数据使用**：说明数据用途
- **数据保护**：说明数据保护措施
- **用户权利**：说明用户的权利

#### 7.2.2 政策展示
- **首次使用**：显示隐私政策摘要

## 8. 异常处理

### 8.1 数据获取异常

#### 8.1.1 权限被拒绝
- **处理方式**：显示权限说明和设置入口
- **替代方案**：仅使用呼吸练习数据
- **不强制**：不强制用户授权

#### 8.1.2 数据不足
- **处理方式**：显示"数据不足"提示
- **说明原因**：需要更多数据才能生成报告
- **引导用户**：引导用户完成更多练习

#### 8.1.3 数据异常
- **处理方式**：过滤异常数据
- **数据验证**：验证数据合理性
- **错误提示**：数据异常时提示用户

### 8.2 报告生成异常

#### 8.2.1 生成失败
- **处理方式**：显示错误提示
- **重试机制**：提供重试按钮
- **降级方案**：显示简化版报告

#### 8.2.2 数据加载慢
- **处理方式**：显示加载指示器
- **优化策略**：优化数据查询和计算
- **缓存机制**：使用缓存减少加载时间

### 9.1 数据查询优化

#### 9.1.1 查询策略
