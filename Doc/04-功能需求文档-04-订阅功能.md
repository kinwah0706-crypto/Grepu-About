# 功能需求文档 - 订阅功能

---

## 1. 功能概述

订阅功能是Grepu的商业模式核心，通过StoreKit 2实现iOS应用内订阅，提供免费版和订阅版两种用户权限，解锁高级功能。

---

## 2. 订阅方案

### 2.1 订阅类型

#### 2.1.1 月度订阅
- **价格**：¥28/月
- **周期**：1个月
- **自动续费**：是
- **试用期**：无（或7天免费试用）

#### 2.1.2 年度订阅
- **价格**：¥268/年
- **周期**：12个月
- **自动续费**：是
- **试用期**：无（或7天免费试用）
- **优惠**：相当于¥22.3/月，节省约20%

### 2.2 功能对比

| 功能 | 免费版 | 订阅版 |
|------|--------|--------|
| 基础呼吸引导 | ✓ (3种) | ✓ (全部) |

### 3.3 支付流程

#### 3.3.1 StoreKit集成
- **使用StoreKit 2**：iOS 15.0+原生支持
- **产品ID配置**：
  - 月度订阅：`com.app.guipu.subscription.monthly`
  - 年度订阅：`com.app.guipu.subscription.yearly`

#### 3.3.2 支付步骤
1. 用户选择订阅类型
2. 点击"立即订阅"
3. 调用StoreKit购买API
4. 弹出系统支付确认
5. 用户使用Face ID/Touch ID/密码确认
6. 等待支付结果
7. 验证收据
8. 更新用户权限
9. 显示成功页面

#### 3.3.3 支付状态处理
- **成功**：显示成功页面，更新权限
- **失败**：显示错误提示，允许重试
- **取消**：静默返回，不显示错误
- **待处理**：显示处理中提示

## 5. 权限控制

### 5.1 权限检查

#### 5.1.1 检查时机
- **应用启动**：检查订阅状态
- **功能使用前**：检查功能权限
- **定期检查**：每24小时检查一次

#### 5.1.2 检查逻辑
```swift
func checkSubscriptionStatus() -> SubscriptionStatus {
    // 从StoreKit获取订阅状态
    // 验证收据
    // 返回状态
}

func hasAccess(to feature: Feature) -> Bool {
    switch feature {
    case .premiumBreathing:
        return subscriptionStatus == .premium
    case .unlimitedPractice:
        return subscriptionStatus == .premium
    case .fullReport:
        return subscriptionStatus == .premium
    case .premiumTheme:
        return subscriptionStatus == .premium
    default:
        return true
    }
}
```

### 5.2 功能限制

#### 5.2.1 呼吸引导限制
- **免费用户**：每日3次
- **检查逻辑**：
  - 记录每日使用次数
  - 达到限制时显示升级提示
  - 重置时间：每天0点

#### 5.2.2 元素限制
- **免费用户**：只能解锁5种基础元素
- **检查逻辑**：
  - 检查已解锁元素数量
  - 达到限制时显示升级提示
  - 订阅用户无限制

#### 5.2.3 报告限制
- **免费用户**：只能查看最近7天数据
- **检查逻辑**：
  - 检查数据时间范围
  - 超出范围时显示升级提示
  - 订阅用户可查看全部历史

#### 5.2.4 主题限制
- **免费用户**：仅可使用默认主题（Default）
- **检查逻辑**：
  - 主题选择前校验`Feature.premiumTheme`
  - 不满足条件时弹出升级提示弹窗
  - 订阅用户可使用全部主题（含Serenity、Aurora）

### 5.3 降级处理

#### 5.3.1 订阅过期
- **功能降级**：高级功能立即不可用
- **数据保留**：用户数据保留
- **提示用户**：显示过期提示和续费入口

#### 5.3.2 已解锁内容
- **已解锁元素**：保留，但不能再解锁新元素
- **历史数据**：保留，但只能查看最近7天
- **成就**：保留所有成就
- **主题**：自动回退至默认主题，保留用户的首选记录以便续订后恢复

## 7. 订阅恢复

### 7.1 恢复场景
- **换设备**：在新设备上恢复订阅
- **重装应用**：重新安装应用后恢复
- **用户主动恢复**：用户点击"恢复购买"

### 7.2 恢复流程
1. 用户点击"恢复购买"
2. 调用StoreKit恢复API
3. 验证收据
4. 恢复订阅状态
5. 更新用户权限
6. 显示恢复结果

### 7.3 恢复结果
- **成功**：显示"订阅已恢复"
- **失败**：显示"未找到有效订阅"
- **部分恢复**：显示恢复的订阅信息

## 8. 订阅分析

### 8.1 数据统计
- **订阅转化率**：免费用户转订阅用户比例
- **订阅留存率**：订阅用户续费率
- **ARPU**：每用户平均收入
- **LTV**：用户生命周期价值

### 8.2 分析指标
- **订阅入口点击率**：各入口的点击率
- **订阅完成率**：进入订阅页面到完成订阅的比例
- **订阅类型偏好**：月度vs年度订阅比例
- **取消原因**：用户取消订阅的原因（如可获取）

## 9. 异常处理

### 9.1 支付异常
- **网络错误**：显示网络错误提示，允许重试
- **支付失败**：显示支付失败提示，允许重试
- **收据验证失败**：显示验证失败提示，联系客服

### 9.2 状态异常
- **状态不同步**：强制刷新订阅状态
- **权限错误**：重新验证收据
- **过期未检测**：定期检查并更新状态
